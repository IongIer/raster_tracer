HamiltonFastMarching

Source: https://github.com/Mirebeau/HamiltonFastMarching
Upstream commit: 420533c742d46f1d17145fa31b8167529be7182d
Python adaptation and plugin integration: 2026-09-26, Raster Scribe.
The GPL version 3 text referenced in the original notice below is in LICENSE.

The Python port adapts the first-order Elastica2 solver and ODE/Discrete
geodesic extraction, plus a fixed stencil table. Adapted sources:
Headers/Base/Implementation/HamiltonFastMarching.hxx, EulerianStencil.hxx
and HFM_StencilShare.hxx; ExtraAlgorithms/WallObstructionTest.h;
GeodesicODESolver.hxx and GeodesicDiscreteSolver.hxx; and the Elastica2<5>
SetStencil method in Headers/Specializations/Curvature2.h.

The port fixes xi=24, eps=0.1, 16 headings, gridScale=1, first-order updates,
scalar color costs and unoriented endpoint seeds. Numerical stencils were
extracted offline from unmodified upstream code. The port uses Python and
NumPy; no upstream binary is included.
