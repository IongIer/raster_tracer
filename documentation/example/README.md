# Tracing example

Copy this directory before editing, then open `example.qgs` in QGIS.
Follow [Trace your first line](../usage.md#trace-your-first-line).

- `line.tif`: a generated RGB raster with a black curve.
- `traced-lines.gpkg`: an empty MultiLineString layer in EPSG:3857.
- `example.qgs`: a project with both layers and relative file paths.
- `example_attachments.zip`: auxiliary data saved by QGIS with the project.

These files were generated for this tutorial using
[`scripts/create-example.py`](../../scripts/create-example.py). The example
data may be used, copied, and modified without restriction (CC0-1.0).
